# 🚀 CI/CD Pipeline Demo - AWS DevOps Project

This project demonstrates a complete CI/CD pipeline using AWS services. A sample web app is automatically built, tested, and deployed to an EC2 instance using CodePipeline, CodeBuild, and CodeDeploy.

---

## 📌 Tech Stack
- AWS CodePipeline
- AWS CodeBuild
- AWS CodeDeploy
- EC2
- S3
- GitHub
- IAM
